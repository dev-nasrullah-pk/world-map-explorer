# 🗺️ World Map & Location Explorer

An interactive, responsive Web Application built with pure HTML5, CSS3, and Vanilla JavaScript. This project enables users to seamlessly explore global cities, dynamically load map views, and pinpoint their real-time geographical position.

---

## ✨ Key Features

* **Global Location Switching:** Instant interactive buttons to navigate between major global cities and preview their map views.
* **Real-time Geolocation:** Integrated Browser Geolocation API (`navigator.geolocation`) to detect and pinpoint the user's current position on the map with a single click.
* **Dynamic Map Rendering:** Seamlessly updates map coordinates and location previews without page reloads.
* **Responsive & Clean UI:** Designed with modern CSS layout techniques (Flexbox & CSS Variables) for a smooth desktop and mobile user experience.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic elements and structured UI framework.
* **CSS3:** Custom styling, responsive button groups, rounded card designs, and dynamic UI feedback.
* **JavaScript (ES6+):** Event delegation, DOM manipulation, Geolocation API integration, and modular code architecture.
